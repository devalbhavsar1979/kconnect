PWA Icon Placeholders
=====================
Replace the files in this directory with real PNG icons before deploying to production.

Required files:
  icon-192.png   192×192 px   Standard PWA icon
  icon-512.png   512×512 px   Large PWA icon / maskable

Tools to generate icons:
  https://realfavicongenerator.net
  https://maskable.app

Design direction:
  Background: #0f1729 (deep navy)
  Foreground: K letter in #3b82f6 (blue) or white
